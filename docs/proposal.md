# 프로젝트 제안서(Project proposal): 9ood filter

## 1. 프로젝트 주제(Project topic)

### 만들고 싶은 프로그램(What we want to build)

문서 파일에 포함된 개인정보를 자동으로 탐지하고, 지정한 대체 문자열로 변경하거나 삭제하는 Python 패키지를 개발한다. 사용자가 문서를 공유하거나 공개하기 전에 개인정보 노출을 줄일 수 있도록 비식별화 기능을 제공한다.

### 사용자 정의 및 해결할 문제(Users and problem)

개인 문서를 검토하거나 공유하는 학생, 연구자, 소규모 조직 등을 주요 사용자로 한다. 문서에 이름, 이메일 주소, 전화번호 등의 개인정보가 포함되어 있는지 사람이 직접 확인하면 시간이 오래 걸리고 일부 항목을 놓칠 수 있다. 이 프로그램은 문서에서 지원하는 개인정보를 자동으로 탐지하고 마스킹하여 반복적인 검토 작업을 줄여 준다.

## 2. 개발할 기능(Planned features)

### 입력(Input)

- 사용자가 선택한 `.txt` 또는 `.md` 형식의 문서 파일
- 비식별화 대상 개인정보 유형: 이름, 이메일 주소, 전화번호, 주민등록번호, 계좌번호 등
- 개인정보 유형별 대체 문자열 설정 (예: `[이름]`, `[이메일]`, `[전화번호]`)
- 개인정보를 대체하는 대신 삭제하는 옵션
- 사용자가 처리를 원하지 않는 문자열 지정
- **지원하는 문서 파일 형식은 개발 진행 상황과 팀 논의에 따라 변경하거나 확장할 수 있다.**

### 처리(Processing)

1. 입력 파일의 형식과 내용을 확인한다.
2. 파일에서 텍스트를 읽어 온다.
3. 정규표현식 및 사전에 정의된 탐지 규칙을 사용하여 개인정보를 탐지한다.
4. 탐지한 개인정보를 유형별로 분류한다.
5. 사용자가 설정한 대체 문자열로 변경하거나 해당 문자열을 삭제한다.
6. 변경 전후의 항목 수를 개인정보 유형별로 집계한다.
7. 비식별화된 내용을 새로운 파일로 저장한다.

### 결과(Output)

- 개인정보가 비식별화된 문서 파일
- 개인정보 유형별 탐지 및 대체 항목 수 요약
- 입력 파일은 변경하지 않고 별도의 결과 파일로 저장한다.
- 탐지된 실제 개인정보는 요약 결과에 표시하지 않는다.
- 결과 파일 형식은 입력 파일의 형식을 유지한다.

### 개발 범위(Scope)

- **포함할 기능(In scope):**
  - `.txt`, `.md` 문서 파일 읽기
  - 이름, 이메일, 전화번호, 주민등록번호, 계좌번호 등 개인정보 탐지
  - 개인정보 유형별 대체 문자열 설정
  - 탐지한 개인정보 마스킹 및 삭제
  - 개인정보 유형별 처리 결과 통계 제공
  - 비식별화된 새 문서 파일 저장
  - 개발 진행 상황에 따른 지원 문서 형식의 변경 및 확장

- **제외할 기능(Out of scope):**
  - 이미지 내부의 개인정보 탐지
  - 실시간 개인정보 모니터링
  - 외부 서버를 이용한 개인정보 분석
  - 문맥을 분석한 모든 종류의 개인정보 자동 식별

- **한계(Limitation):**
  - 정해진 탐지 규칙으로 확인할 수 없는 개인정보는 탐지하지 못할 수 있다.
  - 이름이나 주소처럼 문맥에 따라 의미가 달라지는 정보는 정확한 탐지가 어려울 수 있다.
  - 지원하는 문서 형식에 따라 일부 서식이나 구조가 유지되지 않을 수 있다.
  - 비식별화 결과에 개인정보가 남아 있을 수 있으므로 사용자가 최종 결과를 확인해야 한다.

### 사용 예시(Usage example)

사용자가 개인정보가 포함된 `personal_data.txt` 파일을 입력한다. 프로그램은 문서에서 전화번호, 이메일, 주민등록번호 등의 개인정보를 탐지하고, 각 유형에 설정된 대체 문자열로 변경한다. 이후 개인정보 유형별 처리 항목 수를 요약하고 비식별화된 문서를 `personal_data_anonymized.txt`라는 새 파일로 저장한다. 사용자는 결과 파일을 확인한 뒤 개인정보가 적절하게 처리되었는지 검토한다.
